# ConferBack

Інформаційна система підтримки лідогенерації на конференціях і виставках
(магістерська кваліфікаційна робота, Діденко А. В., ІТУП-21з).

Система веде кампанію участі в події від рішення про поїздку до обчислення окупності:
планування й кошторис, оцінка доцільності, цільовий список, запис розмов на заході
(також без мережі), черга фолоу-апів, угоди, аналітична дошка і звіт.

## Технології
Python 3.10+, Flask, SQLite (стандартний модуль `sqlite3`), Bootstrap 5 (файли лежать у проєкті).

## Запуск на своєму комп'ютері
```bash
pip install -r requirements.txt
python seed_demo.py --yes        # база з демонстраційними даними
flask --app wsgi run             # відкрити http://127.0.0.1:5000
```
Демо-логіни: `head`, `marketer`, `manager`, `rep`, пароль `demo2026`.

Порожня база з власним користувачем:
```bash
flask --app wsgi create-user anna "Анна Діденко" --roles head,marketer,manager,rep
```

## Структура
- `app/schema.sql` — схема бази даних
- `app/calc.py` — формули (3.1)–(3.4): окупність, прогноз, оцінка доцільності, дата фолоу-апу
- `app/stats.py` — показники дошки та звіту
- `app/refs.py` — переліки значень і права ролей
- `app/auth.py` — вхід, ролі, захист форм
- `app/views/` — сторінки: події, цільовий список, ліди й черга, аналітика, довідники
- `app/static/js/capture.js`, `app/static/sw.js` — робота без мережі
- `tests/` — автоматичні тести
